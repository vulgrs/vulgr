Features

Real terminals

xterm.js + node-pty, so agent TUIs, colors and prompts work as in your normal terminal. Find text in a pane and save its output to a file.

Panes, sessions and groups

Split terminals side by side or stacked, each with its own command box. Tabs name themselves, sort into groups and come back on the next launch.

Command box

Run commands as blocks with duration and output, describe a command in plain words with #, or ask Claude with ?.

Agents working together

Duo Loop: one agent writes, another tests. Agent Swarm: writer, checker and auditor on one goal. Orchestrator: a goal split into tasks that agents do in parallel. Pause, stop or restart one agent at any time.

History, tokens and cost

Every run is saved with a map you can replay, the real tokens and cost the agents reported, and a cost limit that stops a run. Run any of them again in one click.

Git built in

AI-written commit messages, commit & push, a branch switcher, and pull requests whose description an agent writes. Review every change before it lands.

Updates itself

A gift icon appears when a new version is ready; one click restarts into it, on macOS, Windows and Linux.

Made to fit in

Eight interface languages, dark and light themes, your own keyboard shortcuts, saved templates for goals and teams, and system notifications when a run ends.

These beta builds are not code-signed yet

Your system will warn you the first time you open Vulgr. This is expected; here is how to open it:

  • macOS: right-click Vulgr in Applications and choose Open, then Open again. If macOS still refuses, go to System Settings → Privacy & Security and click Open Anyway.
  • Windows: when SmartScreen appears, click More info → Run anyway.
  • Linux: make the file executable with chmod +x Vulgr-*.AppImage, then run it.

Or install it with npm and start it with vulgr:

npm install -g vulgr@beta
